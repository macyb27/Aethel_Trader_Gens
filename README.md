# Aether Trader

Monorepo für ein autonomes KI-Handelssystem mit quanten-inspirierten Algorithmen, Agent-Orchestrierung und klar getrennten Schichten für Web, Mobile und Desktop.

## Vision

Marktnahe Entscheidungsfindung mit erklärbarer Risikokontrolle: Strategie-Evolution, Paper-Trading und produktionsreife Safety-Gates, bevor echtes Kapital eingesetzt wird.

## Tech-Stack (Auszug)

- **Apps:** Solid.js + Vite + TypeScript (Web), Expo/React Native (Mobile), Tauri 2 + Rust (Desktop-Shell)
- **Tooling:** pnpm Workspaces, Turborepo
- **Python:** ≥ 3.11 für Backend-, Research- und Infrastruktur-Skripte (siehe `pyproject.toml`)

## Work in Progress

Dieses Repository wird zur finalen Monorepo-Struktur konsolidiert; Pfade, Paketgrenzen und CI werden schrittweise angeglichen. Erwartet derzeit keine stabile Release-Garantie.
